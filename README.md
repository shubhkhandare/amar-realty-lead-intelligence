# Amar Realty — Lead Intelligence & Data Engineering

## Project Overview

This repository contains the implementation and documentation for Amar Realty's 7-day practical technical evaluation.

The objective is to build a reproducible pipeline for permitted public-data discovery, extraction, cleaning, validation, database loading, lead scoring, and final prospect export.

## Target Micro-Markets

- Hadapsar, Pune
- Fursungi, Pune

## Technology Stack

- Python
- Pandas
- BeautifulSoup
- Playwright or Selenium, depending on source requirements
- Regular Expressions
- SQLite and SQL
- Git and GitHub

## Planned Pipeline

1. Confirm prospect criteria and permitted sources.
2. Discover and document suitable sources.
3. Extract permitted data.
4. Clean, normalize, validate, and deduplicate records.
5. Store structured records in a relational database.
6. Score and rank prospects using the prescribed model.
7. Validate quality and export the final dataset.
