# Amar Realty — Lead Intelligence & Data Engineering

## Project Overview

This repository contains the implementation and documentation for Amar Realty's 7-day practical technical evaluation.

The objective is to build a reproducible pipeline for permitted public-data discovery, extraction, cleaning, validation, database loading, lead scoring, and final prospect export.

## Target Micro-Markets

- Hadapsar, Pune
- Fursungi, Pune

## Technology Stack

- Python
- Pandas
- BeautifulSoup
- Playwright or Selenium, depending on source requirements
- Regular Expressions
- SQLite and SQL
- Git and GitHub
